- Design values live in one object (`src/lib/theme/system.ts`) that generates both the CSS custom properties and the typed mirror; components use role tokens only, and `tokens-lint.test.ts` fails on a raw hex or raw px font size, because the Living design track changes the system in one place.
- The five shared chart types live in `chartkit/` and take a `look` of `read` or `data`, draw from tokens and format through `labels.ts`; specialised panel charts (scatter, vibe map, history flows) stay local but take colours from tokens.
- "Copy as CSV" reads the table as shown (headers and cells), skipping cells marked `data-no-csv`, so copied columns always match what the reader sees.
- Terminal parts that arrive after the shell sit in reserved boxes of their final size (the glisten placeholder; the tour stays hidden until placed), and the story list is sent at full height from a small first-view read (`storyQueueHeadQuery`) inside the Today panel rather than a scrolling box, and each brand family has one metric-matched local fallback face per platform font, because the gate fails a page over the layout-shift target.
- Fixed-copy Read headings that wrap differently under the stand-in fonts hold their real-font line count with `hold-*` classes (`styles.css`, screen-only width ranges measured per pixel, 4 px clear of each line-count change); only static text gets a hold, because a fixed height on text that can change would overlap what follows.
- A page-body `<Later>` carries `reserve` (marked `data-later-reserve`) so its placeholder reaches past the screen; the front page's lower modules land together with the top (`FRONT_TOGETHER_MS`) and `/brands` sends its stored directory in the first response (`BRANDS_FIRST_WAIT_MS`), because a nested placeholder cannot know its block's height; `scripts/perf/deferred_heights.py` (dev `?__late=`) measures it. `Count` holds its final width while rolling so a figure never re-wraps its line.
- A ledger's number column exists only when a row has a number and is as wide as that list's longest number (an invisible stand-in in each cell), so unnumbered lists start at the row padding and titles still align.
- Reader GET server functions are cut at `READ_DEADLINE_MS` by the `readDeadline` function middleware and failed reads are never retried silently (QueryClient `retry: false`), so a page always closes and a failed part shows its own retry.
- Deferred slots of one page region sit in one `FailGroup` (`Later.tsx`): several failures show one failed line whose retry drops the failed reads and retries every slot, because a read that failed during the page send otherwise comes back empty and two lines stack in one column.
- The Terminal's panel area, its story list and the ticker's library line each sit in a `PartBoundary` (quiet for the ticker), so a read cut by the reader time limit fails only its own part and never reaches the route's whole-page error; `scripts/perf/terminal_check.py` fails when the first panel has no rows.
- Today's left column is topped up on the server (pure `front/top-up.ts`: measured part heights by kind, ≤5 stories from before this week, shown from 1024 px) and the brand page's sections strip comes with the card (`CARD_TILES_WAIT_MS`, drawn through `Later`'s `fallback`), because measuring after load would move the page.
