- Museum palettes stay pure in `palette.ts` (OKLab, neutrals set aside on both sides, share-weighted symmetric distance, named thresholds) and `contract.ts` (the ingest contract); `ingest.server.ts` and `read.server.ts` only validate, store and read, and every reader surface (brand line, museum study) stays absent until the stored-works threshold passes, so readers never see a match built on too few works.
- `art_works` accepts only CC0 records from the two museum hosts through the crawler-secret `/api/public/ingest-art`; a removed work is refused forever and its thumbnail deleted, because removal on request must stick.
- Every reader museum surface (study, brand-page line in both views, stored records read back) checks `MUSEUM_SHOWN` in `site.ts` through `withheld()` in the data-stories registry, so one editor switch hides them all without touching stored works.
- A palette is compared only through `comparable()` in `palette.ts` (varied by colour family from `src/lib/colour-family.ts`, the same families the study strips draw; media-led first screens refused), and groups pool only comparable works, so the brand line, the study and its check can never match paper, varnish or a photograph.
